# Quality-attribute drills

ATAM-lite practice over the committed quality-attribute definitions in `architecture/content/quality-attributes/`. Each
drill gives a stimulus and asks for the response, a measurable target, and the tactic that improves that attribute.

```bash
just -f quality/justfile list
just -f quality/justfile drill availability
just -f quality/justfile prompts
```

Cards for these definitions are generated by `architecture/tools/build.py` and reviewed through `cards/`.
