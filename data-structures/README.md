# Data structures

> Generated from `content/`. Edit the YAML, then run `tools/build.py`.

Each topic has a write-up, a quiz, and an HTML page. The topics:

- [Hash tables: dict and set](hash-tables/README.md): quiz in `hash-tables/quiz_guide.md`
- [Heaps: a priority queue in a flat list](heaps/README.md): quiz in `heaps/quiz_guide.md`
- [Lists and deques: contiguous arrays versus block lists](lists-and-deques/README.md): quiz in `lists-and-deques/quiz_guide.md`

## Use it

- Regenerate every output: `uv run python data-structures/tools/build.py`
- Test the claims and the outputs: `uv run pytest tests/unit/test_data_structures.py`
- Take the quiz in a terminal: `uv run python data-structures/tools/quiz.py`
- Flashcards for Anki: `flashcards.csv`
