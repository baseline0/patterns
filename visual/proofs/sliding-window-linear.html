Sliding window moves each pointer at most n times

Statement

A sliding window over an array of n elements runs in O(n) time when each pointer only moves forward.

Invariant

At the start of every iteration the half-open interval [left, right) is the current window and right is one past the last inspected element.

Proof graph

Steps

StepDetailDepends on
Empty windowSet left = right = 0. The window is empty and the invariant holds before any input is consumed.
Right pointer only advancesEach iteration admits at most one new element by increasing right, so right advances at most n times.init
Left pointer only advancesInvalid windows are repaired by increasing left; it never decreases, so left also advances at most n times.init
Sum the pointer movesAt most n expansions plus at most n shrink steps gives O(n) total work, with O(1) extra space.expand, shrink

Complexity

O(n) time, O(1) extra space.
