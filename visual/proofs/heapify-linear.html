Bottom-up heapify is linear

Statement

Constructing a binary heap by calling sift-down from the last internal node to the root takes O(n) time.

Invariant

Before node i is processed, every subtree rooted at an index greater than i is already a valid heap.

Proof graph

Steps

StepDetailDepends on
Leaves are heapsNodes with no children already satisfy the heap property, so processing can start at the last parent.
Process internal nodes bottom-upWalking from the last parent down to the root guarantees each child subtree is a heap before its parent is fixed.leaves
Cost depends on heightA node at height h moves at most h levels, and a binary heap has at most ceil(n / 2^(h+1)) nodes at height h.reverse
Bound the weighted sumThe sum over heights of h * n / 2^(h+1) is at most n, because the series sum h / 2^h converges to 2.height-cost

Complexity

O(n) time and O(1) extra space, versus O(n log n) for repeated insertion.
