Dynamic array append is amortized O(1)

Statement

A sequence of n appends to a geometrically growing array costs O(n) time in total.

Invariant

After every append, capacity is at least length; immediately after a resize, capacity is at most twice length.

Proof graph

Steps

StepDetailDepends on
Base caseThe first append writes one slot into the initial capacity and performs no copy.
Resize points form a geometric seriesCapacity doubles only when length reaches capacity, so resizes happen at lengths 1, 2, 4, 8, and so on.base
Total copy work is boundedAcross all resizes the array copies at most 1 + 2 + 4 + ... + n slots, which is less than 2n.doubling
Add writes and copiesn appends perform n writes and fewer than 2n copies, so the sequence is linear and each append is O(1) on average.copies

Complexity

O(n) for n appends; O(1) amortized, O(n) worst case for a single resize.
