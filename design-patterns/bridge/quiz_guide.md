# Quiz: Bridge

> Generated from `content/`.

## 1. Bridge is preferred over inheritance when:

A. Only one implementation will ever exist
B. Two orthogonal dimensions must vary independently
C. Objects must be composed into trees
D. You need to cache remote responses

**Answer: B.** It splits abstraction and implementation into separate hierarchies.

## 2. A sign Bridge may be missing is:

A. Many subclasses named like FeatureXOnPlatformY
B. Need for undo/redo
C. Expensive object creation
D. Tree traversal requirements

**Answer: A.** Combinatorial subclasses indicate abstraction and implementation are tangled.
