# Quiz: Adapter

> Generated from `content/`.

## 1. Adapter primarily addresses:

A. Object creation complexity
B. Interface incompatibility between components
C. Concurrent access control
D. State persistence

**Answer: B.** It translates one interface into another expected by clients.

## 2. In a layered architecture, an adapter commonly lives at:

A. The domain core only
B. An integration boundary such as infrastructure/ports
C. The browser UI exclusively
D. The database index layer

**Answer: B.** Adapters bridge external or legacy systems to internal abstractions at boundaries.
