# Quiz: Template Method

> Generated from `content/`.

## 1. Template Method centralizes:

A. Object construction of families
B. The invariant sequence of an algorithm
C. Network communication retries
D. Persistent storage schemas

**Answer: B.** The base class owns the skeleton; subclasses supply variable steps.

## 2. A drawback compared to composition-based alternatives is:

A. It cannot enforce ordering
B. It depends on inheritance, limiting flexibility
C. It prevents code reuse
D. It only works in functional languages

**Answer: B.** Behavior variation is expressed through subclassing rather than object composition.
