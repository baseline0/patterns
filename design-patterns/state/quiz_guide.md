# Quiz: State

> Generated from `content/`.

## 1. State pattern is a strong fit when:

A. Behavior is identical in all modes
B. An object’s behavior and valid transitions depend on lifecycle phase
C. You need to clone object graphs
D. You need a simplified subsystem API

**Answer: B.** It encapsulates per-state behavior and transitions.

## 2. How does State differ from Strategy conceptually?

A. State is chosen by client only; Strategy never is
B. State transitions are typically driven by context lifecycle, Strategy by interchangeable policy choice
C. State requires databases; Strategy does not
D. They are identical patterns

**Answer: B.** Both delegate behavior, but State models internal lifecycle transitions.
