# Quiz: Dependency Injection

> Generated from `content/`.

## 1. Dependency Injection mainly improves:

A. Network throughput
B. Testability and flexibility by externalizing dependency creation
C. Database normalization
D. Binary size

**Answer: B.** Clients receive collaborators, making substitution and configuration easier.

## 2. A potential downside of DI containers is:

A. They prevent interface use
B. Wiring can become implicit and harder to trace
C. They require no configuration ever
D. They eliminate constructors

**Answer: B.** Automated wiring may hide how objects are composed, so explicitness matters.
