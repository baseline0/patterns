# Quiz: Facade

> Generated from `content/`.

## 1. Facade is primarily about:

A. Enforcing one instance globally
B. Simplifying access to a subsystem
C. Sharing intrinsic state efficiently
D. Deferring execution as commands

**Answer: B.** It provides a higher-level interface over complex components.

## 2. When should clients bypass a facade?

A. Never, facades must hide everything permanently
B. When advanced or uncommon capabilities are legitimately needed
C. Only during testing
D. Whenever performance matters

**Answer: B.** Facades simplify common paths but do not have to forbid direct subsystem access.
