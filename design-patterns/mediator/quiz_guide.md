# Quiz: Mediator

> Generated from `content/`.

## 1. Mediator reduces:

A. The need for any interfaces
B. Direct many-to-many dependencies between colleagues
C. All runtime latency
D. Storage requirements

**Answer: B.** Peers communicate via a central coordinator rather than referencing each other.

## 2. A warning sign when using Mediator is:

A. Colleagues become too reusable
B. The mediator accumulates most business rules and complexity
C. Handlers become stateless
D. Events become immutable

**Answer: B.** Centralization helps decoupling but can create a god object if overused.
