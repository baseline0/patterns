# Quiz: Iterator

> Generated from `content/`.

## 1. Iterator’s key benefit is:

A. Faster sorting algorithms
B. Traversal without exposing internal representation
C. Automatic persistence
D. Distributed consensus

**Answer: B.** Clients consume elements through a standard interface regardless of storage layout.

## 2. In data pipeline code, iterators are useful because:

A. They eliminate backpressure
B. They provide a uniform way to stream records from varied sources
C. They replace message queues
D. They guarantee exactly-once delivery

**Answer: B.** Different sources can expose the same traversal contract to downstream stages.
