# Quiz: Command

> Generated from `content/`.

## 1. Command turns a request into:

A. A database schema
B. A standalone object with execution context
C. A shared mutable singleton
D. A compile-time macro

**Answer: B.** Encapsulation as an object enables queuing, logging, and undo.

## 2. In CQRS-style systems, commands are useful because:

A. They replace read models entirely
B. They represent intentful writes that can be validated, queued, and audited
C. They guarantee eventual consistency without design
D. They eliminate domain logic

**Answer: B.** Commands make write operations explicit and manageable.
