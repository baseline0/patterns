# Quiz: Decorator

> Generated from `content/`.

## 1. Decorator differs from inheritance by:

A. Composing behavior at runtime via wrapping
B. Requiring access to source code
C. Only working for UI widgets
D. Forcing a single global wrapper

**Answer: A.** Decorators wrap objects dynamically, allowing flexible combinations.

## 2. A common operational pitfall of decorators is:

A. They cannot implement interfaces
B. Wrapper order can change semantics and complicate tracing
C. They require database locks
D. They eliminate the need for testing

**Answer: B.** Behavior like auth-before-cache vs cache-before-auth depends on composition order.
