# Quiz: Proxy

> Generated from `content/`.

## 1. A proxy and the real subject typically:

A. Expose unrelated interfaces
B. Share the same subject interface so clients are unaware
C. Must run in different processes
D. Cannot be swapped at runtime

**Answer: B.** Transparency to the client is a core property of Proxy.

## 2. Which is a valid proxy use case?

A. Defining algorithm families
B. Lazy loading or access control around a real object
C. Building objects stepwise
D. Traversing tree structures uniformly

**Answer: B.** Proxies control access for concerns like laziness, protection, remoting, or caching.
