# Site

Autogenerated local interactive explorer for repository content.

- `catalog.json` — machine index discovered from repo structure and committed sources.
- `index.html` — Swagger-like local UI for browsing, searching, and drilling into content.

```bash
just -f site/justfile build
just -f site/justfile check
just -f site/justfile serve   # http://localhost:8000/site/index.html
```

Edit content sources, not these outputs.
